# Python Chatbot

A simple rule-based chatbot that runs in the terminal, written in Python. Built for the first-year Structured Problem Solving module at Liverpool Hope University.

## Files

- `chatbot code.py` is the first version: greetings, a few set questions and jokes
- `chatbot code 2.py` is the improved, fully commented version

## How to run

```
python "chatbot code 2.py"
```

Type a message to chat, or `exit` to quit.
